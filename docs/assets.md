# Материалы

В репозитории только необходимые подготовленные ресурсы. Размеры и SHA-256
проверяются по `assets/manifest.json` перед каждой сборкой.

| Ресурс | Назначение и происхождение |
| --- | --- |
| `space-without-clouds.png` | Небо, замок и звёзды. Получено редактированием предоставленного художественного фона с удалением Земли и неподвижных облаков. Автор и лицензия исходного рисунка не записаны. |
| `earth-surface-v6-clear-ocean.png` | Текущая поверхность v6: география NASA, ночные огни, синяя художественная палитра. Облакоподобные разводы океана убраны нативным Qt-шейдером; суша и города сохранены. |
| `earth-surface-pixel-v8.png` | Сохранённый альтернативный вариант поверхности с теми же источниками. |
| `earth-emission-v8.png` | Карта данных: R — города, G — суша/лёд, B — оценка дневной яркости. |

Исходные данные: [NASA Blue Marble](https://svs.gsfc.nasa.gov/2915/),
[карта суши/океана/льда](https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_8192.png),
[NASA Black Marble](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/),
[ночная карта 2016 года](https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144898/BlackMarble_2016_3km.jpg).
Синяя палитра также использует материал, сгенерированный по художественному
референсу. Эти преобразования не являются неизменёнными изображениями NASA.

`media/` содержит только нативный рендер приложения: снимков настоящего рабочего
стола и содержимого окон в нём нет. Текстовые/EXIF-метаданные в PNG запрещены
проверкой публикации.

Референсы Венеры: [NASA/JPL Mariner 10](https://www.jpl.nasa.gov/images/pia23791-venus-from-mariner-10/),
[ESA Venus Express](https://www.esa.int/ESA_Multimedia/Images/2007/11/Venus_southern_hemisphere_in_the_ultraviolet),
[NASA Galileo](https://science.nasa.gov/resource/venus-cloud-patterns/).
Их изображения в репозиторий не включены.

Автоматической лицензии на чужое художественное изображение не назначено.
Перед публичным распространением этих художественных материалов нужно установить
права на исходный референс. Это не ограничивает локальную сборку приватной копии.
