# Проверка перед отправкой

Для работы приложения не нужны токены, пароли, приватные ключи или сетевые службы.
Авторизация GitHub используется только локальными инструментами публикации;
её значения нельзя помещать в URL remote, исходники, настройки или коммиты.

Перед отправкой:

```sh
python3 scripts/audit.py --history
gitleaks dir . --redact=100 --no-banner
gitleaks git . --redact=100 --no-banner --log-opts=--all
```

`audit.py` проверяет файлы и все Git-объекты истории: известные форматы ключей,
приватные ключи, литералы паролей/токенов, авторизацию в URL, персональные пути,
локальные файлы настроек и текстовые/EXIF-метаданные PNG.
Он также ищет точные значения чувствительных переменных окружения, выводя
только правило, путь и номер строки. Значения секретов в отчёты не попадают.

Дополнительная локальная проверка совпадения с текущим токеном GitHub CLI:

```sh
python3 scripts/audit.py --history --check-gh-token
```

Токен читается в память из локальной авторизации `gh`; он не сохраняется,
не печатается и не передаётся внешнему сервису сканирования. Gitleaks запускается
локально и дополняет проверку большим набором правил. Автоматические проверки
не являются математической гарантией отсутствия любых возможных секретов.

В Git не входят `build/`, `.publish/`, личный `settings.json`, `.env`, ключи,
журналы, резервные копии и снимки рабочего стола. Нужные файлы добавляются
явным списком. В коммитах публикации используется GitHub noreply-адрес автора.

Если проверка нашла секрет, прекратите отправку, удалите его из файлов и
истории и отзовите его, если он уже передавался внешнему получателю.
